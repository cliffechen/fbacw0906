# 图片文案技能更新与验证记录

日期：2026-09-05。对象：本目录所属的 amazon-supplement-copywriting 便携技能。所有产品案例均为虚构，输出用于维护验证，不是可直接上架的真实产品文案。

## 已实现的行为

- 默认自然克制、清晰且略有温度；从产品事实和买家问题开始，增加美式英文编辑与换品牌检查。
- 四个旧风格入口及子风格保留，语气与信息密度可调，产品证据独立判断。
- 每张图按任务交付主标题、支撑句、必要事实标签、视觉建议、依据、限定说明及不同角度的备选。关键词不再强制占据图片标题首位。
- 按请求范围交付；无词库也可写。商品标题、五点和完整包仍可用；Basic/Premium 与 Brand Story 分开。
- 修正无来源调研、机械替换 supports、竞品证据迁移和把历史页面当平台许可等规则。官方来源与核验日期保存在版式及声明参考中。
- 原始研究素材保留，核心流程没有新增必需运行时、联网或工具依赖。

## 验证方法与可复核材料

先保存旧版技能快照，再由两名互不读取对方结果的评测代理分别运行相同的 [C1–C6 原始输入](scenarios.md)。每个版本各生成一次，各案例作为独立请求处理；同一版本的六例在同一评测代理内顺序完成，因此不是六个完全隔离会话，也不是重复抽样实验。

首轮完整结果保留原貌：

- [旧版输出](outputs/baseline.md)
- [新版首轮输出](outputs/updated-initial.md)
- [独立对比评审全文](outputs/comparison-review.md)

对比评审只看案例输入与匿名 A/B 成稿，未读技能、计划或版本映射；评审时 **A 对应新版首轮，B 对应旧版**。评审完成后才在本记录揭示映射。报告中的 review-a.md、review-b.md 分别对应上方新版首轮与旧版输出。

另有独立代理只读检查主流程、指南、四份风格、模板、版式、声明与七份案例之间的矛盾，没有参与文案生成。

## 首轮观察：范围通过，英文质量并非全面优胜

| 场景 | 交付与事实观察 | 独立英文编辑判断 |
|---|---|---|
| C1 独立份装 | 两版均给3张图，未借用竞品成分数量；新版分开消费者文字与设计说明 | 接近；新版行动标题具体，旧版份量表达更利落；新版风味标题还可更直接 |
| C2 罐装粉剂 | 两版均给3张图，用量/水量正确，未编口感或溶解性 | 旧版略优；新版 before breakfast 有不必要的时间暗示，备选 morning setup 不够自然 |
| C3 胶囊完整包 | 两版均给3个商品标题、五点、3张图及 A+；新版明确 Basic、用2模块，旧版用5模块 | 新版整体更自然，减少关键词硬拼；新版主推标题仍需明确200 mg的计量对象 |
| C4 只有产品资料 | 两版均直接完成2张图，标记买家假设，没有强加女性或美容定位 | 旧版直接展示剂量更好；两版都补写了原输入未确认的 bottle |
| C5 竞品评论 | 两版均给3张图，评论功效未进入本品文案；新版明确区分评论线索与本品事实来源 | 旧版 One packet is one serving. 更自然；新版工作场景标题也清楚 |
| C6 无依据主张 | 两版均给2张图+2个 Premium 模块，删除无据功效/百分比/认证/商标 | 接近；新版每周粒数计算虽然正确，但没有必要增加阅读负担；两版均需去掉未确认的 bottle |

新版首轮共16张副图、4个 A+ 模块；20项均有推荐与备选标题。仅请求副图的案例未额外生成商品标题或五点。C3 新版商品标题实际为62、42、55字符，标注准确；旧版实际为88、92、92字符，标注也准确，但超过本次核验的现行75字符要求。

结构完整不代表英文更好；首轮结果不能描述为“六例新版全部胜出”。两版总体保持了正确的每日用量、每份剂量与份数计算，也都没有迁移竞品疗效、认证或调查数据。包装假设与标题含义仍需修正，不能据“未编功效”判所有事实均通过。

## 根据实际发现修正

1. **教学示例的配件来源**：Onnit 示例只给“一份一勺”却写 scoop included；已在假设事实中明确内附量勺。
2. **容器类型**：主流程和编辑指南明确未提供时不补 bottle/box/tub；可用总粒数、总袋数或份数表达，画面引用实际包装。
3. **场景与服用时间**：早餐场景留给画面，不新增餐前/空腹等标签未要求的指令，内部备注不能替消费者可见标题消歧。
4. **剂量对象**：商品标题也需要分清营养素含量和化合物总重，不能只靠正文补救；必要时把完整剂量留到五点或剂量图。
5. **直接的信息优先**：剂量图先给实际剂量，不先自评 clearly stated；一袋与一份的关系直接说明，不为了新颖写绕口句。
6. **备选和 A+ 的相关性**：备选仍回答同图问题；没有新信息的支撑句可省略。A+ 允许有用的用法重述，不为制造差异增加没有购买用途的每周换算。

针对上述问题的定向复验保留原产品资料，范围为 C2 三张图、C3 仅商品标题、C4 两张图、C5 仅份量/准备图、C6 两张图和两个 Premium 模块。定向复验与首轮完整测试分开记录，不用修订后的句子覆盖原始首轮证据。

### 定向复验结果

由另一名未读历史输出和评审的代理按修订后技能生成，原始结果见 [定向复验成稿](outputs/targeted-retest.md)。共8张副图、2个 Premium A+ 模块和3个商品标题；C1 未发现需要改动的事实错误，不额外重跑。本轮由主代理复核事实、范围和已报告的问题，没有再做一轮匿名偏好评审。

| 检查项 | 本轮实际结果 |
|---|---|
| C2 标签与早餐场景 | 推荐标题为 Start with one level scoop.；消费文字保留10 fl oz冷水、每日一平勺，早餐只作为画面背景，不再写 before breakfast。风味备选仍围绕 pineapple flavor，省略了重复支撑句 |
| C3 剂量标题 | 主推明确 200 mg Magnesium per Serving；三版实测72、55、68字符，均不超过75字符 |
| C4 实际剂量与未知包装 | 推荐标题直接使用 25 mcg of D3 per softgel.；正文保留1,000 IU、成人每日随餐一粒。使用90 softgels和90天，不再补写 bottle |
| C5 份量解释 | 推荐标题 One packet is one serving.；支撑句明确6 g粉袋与12 fl oz水，不加水温、搅拌时长或效果 |
| C6 包装、计算与证据 | 未再补写瓶/盒，保留60粒、每份2粒、成人每日随餐2粒及30份/30天；删除每周14粒的额外换算，无据功效/94%/认证/商标仍未进入消费者文案 |

上述事实与指定范围问题已消除。英文仍是编辑判断而非自动质量保证：例如复验 C6 的 Keep your multi with mealtime. 搭配仍较生硬，实际选稿可采用同图已经提供的 Two capsules. One daily serving.，由支撑句保留随餐条件。本次没有为这一句再增加全局禁词或强制模板，也不把定向复验称为所有标题都优于旧版。

## 结论的边界

本次验证覆盖文字生成、交付范围、剂量口径、来源隔离和核心迁移。没有生成最终图片、进行手机端成图预览、操作 Amazon 后台、招募美国买家或运行销售实验；六个案例也没有复杂的正向临床证据。因此不能据此宣称手机可读性、平台通过率、研究适用性或转化率已经得到验证。

下一次真实产品使用时，可把实际英文偏好与修改原因补入维护记录；确认是可重复的问题后再改规则，不将单次风格偏好升级为所有产品的强制格式。
